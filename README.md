# Eatzy 🍱 점심 투표

링크 하나를 팀원들과 공유해서 근처 맛집 후보에 다같이 투표하는 웹앱입니다.

## 기능

- **맛집 찾기**: 기준 위치 반경 안에서 한식, 중식, 양식, 분식 카테고리별로 한 곳씩 후보를 뽑습니다. 데이터는 카카오 로컬 API에서 가져옵니다.
  - 이전에 나왔던 가게는 피해서 매번 다른 곳을 뽑습니다. 카테고리의 가게를 한 바퀴 다 돌면 기록을 비우고 다시 시작합니다.
  - 직전에 최종 결정된 가게는 다음 투표 때 같은 카테고리 자리에 다시 나옵니다("지난 투표 1위" 표시). 단, 현재 기준 위치 반경 안에 있을 때만입니다.
- **기준 위치 지정**
  - 📍 내 현재 위치로 갱신 (브라우저 위치 권한 필요, HTTPS 또는 localhost에서만 동작)
  - 🔎 장소 검색해서 지정 (예: 역 이름, 건물 이름)
  - 🏢 기본 위치 (`DEFAULT_PLACE_QUERY`, 기본값은 `더존을지타워`)
  - 반경: 300m, 500m, 1km, 1.5km, 2km 중 선택
- **투표**: 브라우저당 1표이며 바꾸거나 취소할 수 있습니다. 득표 현황은 3초마다 자동으로 갱신됩니다.
- **동점 랜덤 뽑기**: 1위가 2곳 이상이면 🎲 버튼이 나타납니다. 서버에서 한 번만 뽑아 모두에게 같은 결과를 보여 줍니다. 투표가 바뀌어 동점 조합이 달라지면 결과는 무효가 됩니다.
- **완료 (관리자)**: 관리자 키를 입력해야 확정됩니다(기본값 `hs`, 환경변수 `ADMIN_KEY`로 변경 가능). 키는 서버에서만 검증하며 화면 코드에는 들어 있지 않습니다. 확정되면 모든 사용자 화면에 결정된 가게가 표시됩니다.
- 투표가 진행 중인데(1표 이상) 후보를 다시 뽑으려면 관리자 키가 필요합니다. 진행 중인 투표가 실수로 날아가는 것을 막기 위해서입니다.

## 준비: 카카오 REST API 키

1. https://developers.kakao.com 에서 애플리케이션을 만듭니다.
2. **앱 키 > REST API 키**를 복사합니다.
3. 호출 시 403 오류가 나면 콘솔에서 카카오맵(로컬 API) 사용 설정이 켜져 있는지 확인하세요.

API 키가 없으면 앱은 가짜 가게를 만들어 내지 않고 "KAKAO_REST_API_KEY가 설정되지 않았다"는 오류를 표시합니다.

## 로컬 실행

```bash
npm install
KAKAO_REST_API_KEY=발급받은키 npm start
# http://localhost:3000
npm test   # 카카오 API를 가짜 응답으로 대체한 테스트
```

## 환경변수

| 이름 | 설명 | 기본값 |
| --- | --- | --- |
| `KAKAO_REST_API_KEY` | 카카오 REST API 키 (필수) | 없음 |
| `ADMIN_KEY` | 완료/재추첨 관리자 키 | `hs` |
| `DEFAULT_PLACE_QUERY` | 기본 위치 검색어 | `더존을지타워` |
| `DEFAULT_ORIGIN_X`, `DEFAULT_ORIGIN_Y` | 기본 위치 좌표를 직접 고정 (경도, 위도) | 없음 (검색 결과 사용) |
| `DATA_DIR` | 투표 데이터(JSON) 저장 폴더 | `./data` |
| `PORT` | 포트 | `3000` |

## 클라우드 배포

Node 서버 하나에 데이터를 JSON 파일로 저장하는 구조입니다. 그래서 **서버 1대(인스턴스 1개)로 운영**해야 하고, 지난 결정 기록을 유지하려면 `DATA_DIR`이 **영구 디스크**를 가리켜야 합니다. 영구 디스크가 없으면 재배포나 재시작 때 기록이 초기화됩니다. 진행 중인 투표와 "지난 1위 다시 노출", "중복 없이 뽑기" 기록이 모두 사라집니다.

- **Render**: 저장소를 연결하면 `render.yaml`이 적용됩니다. 대시보드에서 `KAKAO_REST_API_KEY`와 `ADMIN_KEY`를 입력하세요. 기록을 유지하려면 Disk를 붙이고 마운트 경로를 `DATA_DIR`로 지정하세요. 무료 플랜의 디스크 지원 여부와 유휴 시 절전 정책은 바뀔 수 있으니 Render 문서에서 확인하세요.
- **Docker 기반 서비스** (Railway, Fly.io, Cloud Run, 사내 서버 등): 포함된 `Dockerfile`을 사용합니다. 기본 저장 경로는 `/data`이므로 그 경로에 볼륨을 마운트하세요.
  ```bash
  docker build -t eatzy .
  docker run -p 3000:3000 -e KAKAO_REST_API_KEY=... -e ADMIN_KEY=... -v eatzy-data:/data eatzy
  ```

"내 현재 위치" 기능은 브라우저 정책상 HTTPS에서만 동작합니다. 위 클라우드 서비스들은 기본 도메인에 HTTPS를 제공합니다.

## 구조

```
server.js          진입점 (환경변수 읽기, 서버 시작)
src/app.js         API 라우트
src/lunch.js       후보 뽑기, 집계, 동점 처리
src/kakao.js       카카오 로컬 API 호출
src/store.js       JSON 파일 저장소
public/            화면 (HTML/CSS/JS, 빌드 없음)
test/              테스트
```
