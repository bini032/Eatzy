# Eatzy 🍱 점심 투표

링크 하나를 팀원들과 공유해서 점심 가게 후보에 다같이 투표하는 웹앱입니다. 투표하는 사람은 링크만 열면 되고, 회원가입이나 설치가 필요 없습니다.

## 기능

- **맛집 찾기**: 한식, 중식, 양식, 분식 카테고리별로 한 곳씩 후보를 뽑습니다.
  - 이전에 나왔던 가게는 피해서 매번 다른 곳을 뽑습니다. 카테고리의 가게를 한 바퀴 다 돌면 기록을 비우고 다시 시작합니다.
  - 직전에 최종 결정된 가게는 다음 투표 때 같은 카테고리 자리에 다시 나옵니다("지난 투표 1위" 표시).
- **투표**: 브라우저당 1표이며 바꾸거나 취소할 수 있습니다. 득표 현황은 3초마다 자동으로 갱신됩니다.
- **동점 랜덤 뽑기**: 1위가 2곳 이상이면 🎲 버튼이 나타납니다. 서버에서 한 번만 뽑아 모두에게 같은 결과를 보여 줍니다.
- **완료 (관리자)**: 관리자 키를 입력해야 확정됩니다(기본값 `hs`, 환경변수 `ADMIN_KEY`로 변경 가능). 키는 서버에서만 검증합니다. 확정되면 모든 사용자 화면에 결정된 가게가 표시됩니다.
- 투표가 진행 중인데(1표 이상) 후보를 다시 뽑으려면 관리자 키가 필요합니다.
- **기준 위치**: 📍 내 현재 위치(HTTPS 또는 localhost에서만 동작), 🔎 장소 검색(카카오 키가 있을 때만), 기본 위치. 반경은 300m부터 2km까지 고를 수 있습니다.

## 가게 후보를 가져오는 두 가지 방식

앱은 아래 순서로 후보 출처를 정합니다.

1. **가게 목록 파일 `restaurants.json`**에 가게가 있으면 그 목록에서 뽑습니다. 카카오 키가 필요 없습니다.
2. 목록이 비어 있고 `KAKAO_REST_API_KEY`가 있으면, 기준 위치 반경 안의 음식점을 **카카오맵에서 실시간으로 검색**합니다.

둘 다 없으면 앱은 가짜 가게를 만들어 내지 않고, 가게를 등록하라는 안내를 표시합니다.

### 가게 목록 파일 형식

```json
[
  {
    "name": "가게 이름",
    "category": "한식",
    "address": "도로명 주소",
    "phone": "02-000-0000",
    "url": "지도 링크",
    "x": 126.0,
    "y": 37.0,
    "memo": "점심 특선 있음"
  }
]
```

- 필수 항목은 `name`, `category`(`한식`/`중식`/`양식`/`분식` 중 하나)입니다. 나머지는 선택입니다.
- `x`(경도), `y`(위도)를 넣은 가게만 거리가 표시되고 반경으로 걸러집니다. 좌표가 없는 가게는 항상 후보에 들어갑니다.
- 파일을 고치면 서버를 다시 켜지 않아도 다음 "맛집 찾기"부터 반영됩니다.
- `npm run check-places`로 형식 오류와 카테고리별 가게 수를 확인할 수 있습니다. 형식이 틀린 항목은 무시됩니다.
- 카카오맵 등 외부 서비스의 검색 결과를 옮겨 적을 때는 해당 서비스의 이용 정책(저장 허용 범위)을 먼저 확인하세요.

### 카카오 REST API 키 (선택)

1. https://developers.kakao.com 에서 애플리케이션을 만듭니다.
2. **앱 키 > REST API 키**를 복사합니다.
3. 앱 관리 페이지에서 카카오맵(로컬 API) 사용 설정을 켭니다. 호출이 403으로 거부되면 이 설정을 확인하세요.

무료 제공량과 요금, 이용 정책은 바뀔 수 있으니 카카오디벨로퍼스 문서에서 확인하세요.

## 실행

Node.js 20.12 이상이 필요합니다.

```bash
npm install
npm start          # http://localhost:3000
npm test           # 자동 테스트 (외부 API는 가짜 응답으로 대체)
```

설정은 프로젝트 폴더에 `.env` 파일을 만들어 넣으면 됩니다(`.env.example` 참고). Windows, macOS 모두 같은 방식입니다.

## 다른 사람들에게 링크로 공유하기

앱이 켜져 있는 동안에만 링크가 동작합니다. 두 가지 방법이 있습니다.

### A. 내 PC에서 실행하고 임시 링크 만들기 (가입 불필요)

1. `npm start`로 앱을 켭니다.
2. 다른 터미널에서 [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/)를 설치한 뒤 실행합니다.
   ```bash
   cloudflared tunnel --url http://localhost:3000
   ```
3. 출력되는 `https://….trycloudflare.com` 주소를 공유합니다.

- PC와 두 터미널이 켜져 있을 때만 접속됩니다. 실행할 때마다 주소가 바뀝니다.
- 회사 PC라면 외부 터널 사용이 보안 정책상 허용되는지 먼저 확인하세요.

### B. 클라우드에 올려서 고정 링크 쓰기

- **Render**: GitHub 계정으로 로그인한 뒤 이 저장소를 연결하면 `render.yaml`이 적용됩니다. 카카오 검색을 쓸 경우에만 `KAKAO_REST_API_KEY`를 입력하고, `ADMIN_KEY`는 원하는 값으로 설정합니다. 무료 플랜의 조건(유휴 시 절전, 디스크 지원 여부)은 바뀔 수 있으니 Render 문서에서 확인하세요.
- **Docker 기반 서비스** (Railway, Fly.io, Cloud Run, 사내 서버 등): 포함된 `Dockerfile`을 사용하고, `/data` 경로에 볼륨을 마운트합니다.
  ```bash
  docker build -t eatzy .
  docker run -p 3000:3000 -e ADMIN_KEY=... -v eatzy-data:/data eatzy
  ```

투표 데이터는 `DATA_DIR`(기본 `./data`)의 JSON 파일 하나에 저장됩니다. 그래서 **서버는 1대로 운영**해야 하고, 클라우드에서는 `DATA_DIR`을 영구 디스크에 두어야 재시작 후에도 기록이 남습니다. 기록이 사라지면 진행 중인 투표, "지난 1위 다시 노출", "중복 없이 뽑기"가 처음부터 다시 시작됩니다. 가게 목록 `restaurants.json`은 저장소에 함께 들어 있으므로 영향을 받지 않습니다.

## 환경변수

| 이름 | 설명 | 기본값 |
| --- | --- | --- |
| `ADMIN_KEY` | 완료/재추첨 관리자 키 | `hs` |
| `RESTAURANTS_FILE` | 가게 목록 파일 경로 | `./restaurants.json` |
| `KAKAO_REST_API_KEY` | 카카오 REST API 키 (목록이 비어 있을 때 실시간 검색에 사용) | 없음 |
| `DEFAULT_PLACE_QUERY` | 기본 위치 이름 (카카오 키가 있으면 이 이름으로 좌표를 검색) | `더존을지타워` |
| `DEFAULT_ORIGIN_X`, `DEFAULT_ORIGIN_Y` | 기본 위치 좌표를 직접 고정 (경도, 위도) | 없음 |
| `DATA_DIR` | 투표 데이터(JSON) 저장 폴더 | `./data` |
| `PORT` | 포트 | `3000` |

## 구조

```
server.js                진입점 (.env 읽기, 서버 시작)
restaurants.json         가게 목록
src/app.js               API 라우트
src/lunch.js             후보 뽑기, 집계, 동점 처리
src/places.js            가게 목록 읽기와 검사
src/kakao.js             카카오 로컬 API 호출
src/store.js             JSON 파일 저장소
scripts/check-places.js  가게 목록 검사 (npm run check-places)
public/                  화면 (HTML/CSS/JS, 빌드 없음)
test/                    테스트
```
